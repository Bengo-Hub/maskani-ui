# UI sprint 9: Release 4 extensions (by demand)

From Q4 2027, scope agreed per client (SRDD 23.4 and figure 1). API: maskani-api
`docs/sprints/sprint-09-r4-extensions.md`.

| Item | Detail |
|---|---|
| Native apps | Owner and guard apps wrapping the PWA where store presence or background location is needed; the PWA stays the main client |
| Smart meters | Readings arrive by API; the reading round becomes an exception list (no reading, tamper flag, leak alarm) |
| Electronic signatures | Advanced e-signature on agreements and leases in addition to OTP acceptance and wet upload |
| Tenant credit checks | Consent screen and result summary inside the R2 application review |
| Owner voting | AGM and resolution voting by unit entitlement, with quorum, proxy and a results document |
| Assistant | Plain-language help for owners and staff over their own records (balances, schedules, notices), answering only from tenant data the user may see |

## Progress

- [ ] Not started. Each item is scoped and priced with the client before work starts.
